# My Wiki

A lightweight docs site built with VitePress. Sources live in `docs/`, projected by the manifest in `website/docs.ts`. Edit anything under `docs/` and it hot-reloads.

## What's inside

- **Guide**: how it works and the directory layout.
- **Development**: run and build locally.
- **Reference**: FAQ and troubleshooting.
